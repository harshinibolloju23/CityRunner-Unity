# City Runner - 3D Endless Runner (Unity 6)

A Subway Surfers style 3D endless runner game with a city theme, built in Unity 6 using C#.

## Features
- 3-lane endless runner with jump and slide
- Randomly generated trains, barriers and coin rows
- Railway tracks, trees and a city skyline
- Animated runner character (Mixamo)
- Score, coin counter, Game Over and Restart
- Speed increases as you run

## Controls
A / D or Left / Right: change lane
Space / W / Up: jump
S / Down: slide
R: restart

## Play
Download CityRunnerBuild.zip from the Releases section, extract it and run the .exe
